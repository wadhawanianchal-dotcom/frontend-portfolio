# FE-05 Accessibility Notes

## My Components vs shadcn/ui

### Modal Dialog
- My modal supports opening and closing.
- shadcn automatically manages keyboard focus more completely.
- shadcn provides a more robust accessibility implementation.

### Tabs
- My tabs support switching between panels.
- shadcn includes more complete keyboard navigation and ARIA handling.

### Disclosure
- My disclosure expands and collapses correctly.
- My implementation is simpler, while shadcn components are more reusable and polished.

## What I Learned

- Accessibility requires more than visual appearance.
- ARIA attributes improve screen reader support.
- Keyboard navigation is an important part of accessible UI.
- shadcn saves time by implementing accessibility best practices.
